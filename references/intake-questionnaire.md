# 一次问诊

识别学生现有信息，用下表一次收齐未答字段。不要重复问已确定的内容；“不清楚”是有效答复。若学生上传资料同时提供完整信息并要求开始，视为已完成问诊和启动。

> 为了按剩余时间安排，请一次回复以下信息；不知道可写“不清楚”。回复后我会先体检资料，通过后自动生成全部文件。
>
> 1. 课程名称：
> 2. 考试日期和时间（例如2026-09-24 09:00；跨时区请注明）：
> 3. 每天大约能学习几小时：
> 4. 开卷 / 闭卷 / 不清楚：
> 5. 已知题型和大致分值：
> 6. 试卷满分、及格线：
> 7. 当前基础：零基础 / 听过课但未复习 / 已有部分基础 / 不清楚：

## 归一化与默认值

内部保存每一字段的原回答、采用值、依据状态（学生提供/资料明确/推断/未知）。不把推断回写成事实。

| 字段 | 不清楚或缺省时 |
|---|---|
| 课程名称 | 从资料标题识别；不能识别用“未命名课程”，不按名称猜课程类型 |
| 考试日期时间 | 优先采用本次考试通知；无依据时保持未知，02使用无日期的最小任务队列，明确不能核算剩余天数；只有日期则不计考试当天的复习时间 |
| 每日小时数 | 不私设2/4/8小时；保持未知，列任务估时和完成顺序，不宣称计划可完成 |
| 开闭卷 | 写“不清楚”；按需能独立作答设计，不能声称允许带书、计算器或AI进入考场 |
| 题型及分值 | 从往年题、模拟题、Tutorial和复习资料推断，逐项标推断；无分值依据时保持未知 |
| 满分及及格线 | 已知满分S和及格线L时目标=min(S,L+10)。满分已知而及格线未知时，暂以0.6S为临时及格目标、min(S,0.6S+10)为临时安全目标，明确“60%只是常见情形的规划假设，并非本课程规则”。满分未知时采用高证据核心任务加可用余量的非数值目标；若及格线已知，保留该值并说明安全余量及上限待确认，不能编造满分100分或声称已达到数值覆盖目标 |
| 基础 | 按零基础估时、说明符号和术语；不能把“听过课”当成已掌握 |

考试日期和当前日期使用学生时区；平台提供时区可采用并注明，无法确定时保持日期不确定。相对日期只有在当前日期可靠时才换算。不要再次发问制造多轮问诊，未解决的信息集中写入10；触及无法继续的资料条件则写入唯一缺失报告。

学生给出每天0小时、已过期考试日期、及格线大于满分、互相矛盾日期时不强行生成可行的日期计划，按 [时间规则](time-compression-rules.md) 标记约束异常并提供可读材料/未排期任务，不编造新考试日期。

## 启动与补交

“请生成/开始/帮我做学习包”已包含启动意图，问诊答复后不再问“是否继续”。仅上传文件而未要求生成时，可在这一次问诊末写“回复并说开始即可生成”。

补交资料是一轮新运行；沿用学生未变更的问诊信息并更新当前日期，不重复整套问题。重读全部核心资料并整体重建学习包。
