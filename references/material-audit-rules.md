# 资料体检与依据闭环

## 清点及读取

1. 枚举学生本次提供的全部文件（含附件、子目录和可读取压缩包），分为教材、老师复习/明确重点、日常课件、Tutorial/作业/答案、往年题、模拟/复习题、考试通知、其他。重复副本记录为同一来源组。
2. 标记状态：完整读取、部分读取、无法读取、非课程文件、重复文件。记录可识别的页数/页码、幻灯片号、题号或章节；没有页码不能编造位置。
3. 检查目录与正文、页面连续性、图表/公式、题干及选项、答案对应关系。扫描件要核验OCR尤其是上下标、正负号、单位、表格列关系；文本提取成功不代表图和公式读对。
4. 将已知考试范围逐章映射到实际可读的教材/课件。不明范围时用完整课程目录、授课周次、成套课件或完整复习资料建立临时范围，并说明不确定。只有文件名或零散页不能证明基本覆盖。
5. 全部核心文件须完整读取，所有核心考点、公式、题干和答案须能核验。非核心资料至少清点并说明处理结果；不能把未读内容列为已分析。

“核心”由覆盖必要性决定：缺失后使基本考试范围、重点判断或所需题型的可靠答案链断裂的资料即核心。不得为了通过关卡随意改名为非核心。

## 四项最低标准（AND）

| 关卡 | 通过条件 | 不通过示例 |
|---|---|---|
| G1 范围 | 可读教材/复习课件/日常课件基本覆盖已知考试范围，或有可解释的完整课程范围依据 | 只有2页零散课件；已知必考章完全没有可读教学资料 |
| G2 带答案题目 | 至少一类题目资料具有可读、可对应且可核验的可靠答案，并能支撑拟保留的核心题型/考点 | 只有题无答案；唯一答案附件打不开；有一条答案但无法支撑其他核心题型 |
| G3 核心可读 | 全部核心文件内容及必要图/公式可正确读取 | 只能看到摘要/检索片段，无法核验全文 |
| G4 核心完整 | 没有导致范围、方法或答案链断裂的大面积缺页、乱码、模糊、关键答案缺失 | 必考章缺页；所有核心计算题答案符号模糊 |

四项均通过才继续。不要用一个武断的页数百分比替代对关键缺口的判断。缺失若仅涉及可明确排除的辅助资料且其他材料独立覆盖相关范围，则是非阻断，必须说明影响。

## 阻断与非阻断

- 阻断：按 [唯一报告模板](../templates/missing-material-report.md) 输出 `资料读取与缺失报告.md`，列已读、异常、缺项、可靠性原因、补交动作、待确认信息。不要生成00—10，即使已有部分草稿也不交付。
- 非阻断：缺往年题但完整课件＋可靠答案Tutorial覆盖范围，可以继续；将题型、重点、模拟结构不确定性写入10并在00提示重大风险。
- 辅助原题题干或答案不完整：跳过并在10列明，不补齐原题；不能把其作为必做或模拟卷内容。若一个保留的非核心问题最终仍无可靠答案，07必须明确“资料不足，无法确认”，不得算入可靠练习覆盖；优先从05/06剔除并同步计划。生成题必须可解且答案已验证。
- 冲突使少量非核心内容无法确认：排除该内容并记录。若冲突导致G1/G2/G4不满足则阻断，不能用免责声明绕过。
- 平台不支持读取、输出容量不足、无法保留核验需要的上下文：停止完整包，报告已处理范围及未处理范围，要求提供可读文本、分批材料或由学生明确缩小范围。不得自行声称已分析整门课。

## 内部依据映射（不交付给学生）

可用临时表或平台内笔记，不依赖数据库/脚本。保存在本轮临时工作区，和学生输出目录分离；没有文件工具时用当前上下文维护。

| 表 | 必需字段 |
|---|---|
| 资料表 | S编号、文件、资料类型、独立来源组、读取范围、缺页/模糊位置、核心性及理由、可用范围、状态 |
| 考点表 | K001等、名称、前置K编号、支持的S编号与定位及短摘录、条件/符号/单位、证据层级、冲突、排序分量、预计学习与练习成本、最终取舍 |
| 题目表 | O001/T001/M001、资料原题/原题改编/AI仿题、对应K编号、原题及答案定位或支持推导的材料、改编差异、解法链、条件验证、分值及性质 |
| 冲突表 | 两方原说法及定位、版本/课程匹配、主口径、选择理由、受影响K/题目、是否待确认 |
| 输出表 | 文件及小节、支持的K/题目、计划任务、估时、校验结果 |

原题O001只用于05；专项T001和模拟M001用于06。原题在模拟中再出现也使用M编号并在内部映射到原题，07给独立对应答案，避免跨文件重复编号。K编号是内容导航，不是资料来源编号。

最终00—09不出现S编号、逐项文件名/页码引用或内部评分表。10和缺失报告可用文件名/位置定位问题；它们不是泄露全部依据映射的出口。

## 冲突决策

先检查是否只是版本、适用条件、单位或题干不同；不能确认相同条件时不要假称矛盾已消除。相同条件下按老师复习/明确重点、课程标准答案的权威口径优先于普通材料；复习课件与Tutorial答案直接矛盾时，若无更明确勘误或老师指示，主讲解按复习课件，10保留双方原说法并注明需向老师核实。

明确的老师勘误优先于被纠正的旧文件。两个同等权威且适用范围相同的口径无法判断时，不自行选边。证据强弱是课程口径选择，不足以证明数学/逻辑上矛盾的答案正确；不能强行给出虚假计算过程。仍无法形成可靠解法的题排除或阻断。

## 题目生成的封闭规则

- 资料原题：仅排版整理，不改变条件、选项、问题和含义；原题不完整跳过。
- 原题改编：显式记录母题和变动。允许在原有取值范围、单位、方法内换数或调整问法；重新计算答案并检验全部条件。
- AI仿题：允许组合资料内的考点和已示范的方法形成新题；内部逐步映射每项知识/条件，组合不增加新方法或新的隐含假设。零依据不能生成。
- 原题答案优先采用课程可靠答案，说明题与答案冲突。改编/仿题答案是依据资料方法重新推演所得，不标成老师标准答案；核验可用代回、反算、逐条件检查或与资料评分要点对照。
- 模拟卷默认按分值约70%资料原题/改编或明确高频题型，约30%AI仿题；统计互斥：新创且标AI仿题的题即使属高频题型也只能计30%桶。分值全未知则按题数，披露口径。材料不足可调比例，绝不为凑比例增加知识。缺失的来源类别不虚构存在。
- 每道模拟题分值、总分、选择题选项与正确答案、主观题关键词、必要计算过程必须自洽。自拟分值/结构在卷首统一说明，题目正文不泄漏答案、类型或高频程度。
