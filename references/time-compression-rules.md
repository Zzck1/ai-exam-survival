# 可用时间、压缩与极限保命模式

在[考点排序](exam-point-ranking.md)后执行。输入为一次问诊结果、当前本地日期、候选K及前置依赖、带可靠答案的题目、任务耗时估计。输出为最终四层取舍与 `02_每日冲刺任务清单.md`，不安排上午、下午、晚上或具体小时段。

## 1. 核算预算，不偷用考试当天

- 使用学生明确的考试日期/时区；未指定时采用当前运行环境本地日期并在重大边界风险中说明采用的时区。不能把未知考试时间当成当天晚上。
- 令 `D = 考试本地日期 − 当前本地日期` 的日历天数。D≥1时，仅将今天至考试前一天列入每日计划；每个日期恰好一行或一节。考试当天不计入默认预算。
- 学生给出的每天学习时长 H 是每日上限，不是必须填满的目标。已说明今天仅有部分时间时使用实际剩余时长；未说明时把今天的 H 标为“按问诊日预算，今日剩余可用时间未单独确认”。已说明不可学习的日期预算记0。
- `B = 各计划日期可用小时之和`。为估时误差与次日补漏预留20%，核心任务预算 `B_core = 0.80 × B`；20%是规划缓冲约定，不是学习效率事实。每日也遵守80%核心任务上限，剩余用于补漏和核对。
- 任务耗时用明确标注的区间，不写精确到分钟的伪精度；安排时采用上界。估时由所选材料篇幅、题目步骤数、学生基础和必要核对动作决定；缺少依据则标注“耗时未知”，不宣称已完成可行性证明。
- 练习时间包括作答及到07核对、修正；学习时间包括必要前置；模拟包括完成及复盘。相同前置只计一次，但不能把还没学的前置当已学。

D>7时仍按短期应试任务编排，不扩展成系统课程；可以增加间隔回忆、一次复核和实战练习，但不得为填满日期引入上传资料之外的知识。早于考试前一天完成核心内容时，后续日期安排轻量回忆或明确“核心完成后机动，无新增必学内容”。

## 2. 未知或异常输入的保守处理

一次问诊允许“不清楚”；非资料阻断信息不能触发反复问诊或暂停等待。将问题写入风险后采用以下分支：

| 情况 | 处理 |
|---|---|
| 日期已知、时刻未知，D≥1 | 仍计划到考试前一天，不计考试当日；记录时刻未知。 |
| 日期未知 | 不虚构考试日期或剩余天数；02改为“临时无日期优先任务队列”，仅保留最小核心任务包及候补。标注保守极限模式、无法核算总预算和安全覆盖；不把队列第1轮称为真实第1天。 |
| 日期已知、H未知 | 列真实日期，但不分配未经证实的固定题量到每一天；提供按顺序领取的最小任务包、每个日期的先补漏后推进规则及最后一天复核动作。说明日负荷尚未核实，不能宣称时间可行；保守极限模式。 |
| 日期与H都未知 | 合并为一个无日期最小任务队列；不默认3天或每天2小时。 |
| 考试就在今天（D=0） | 02说明不存在“今天至考试前一天”的日期区间；改为考试前应急顺序：查看重大风险/考试规则→09已有知识回忆→只核对最高价值错误。默认不新开考点、不计入任何未经确认的剩余小时；保守极限模式。若已知考试已开始或结束，不建议继续考前学习。 |
| 日期已过去（D<0） | 02明确日期已过，暂停编排未来冲刺日程；其余经体检可生成的资料仅作为待新考试日期的参考包。00/01/10写明日期问题，不能展示普通模式或伪造新日期。 |
| H=0或全部可用日期预算为0 | 不安排必完成的新知识、练习或模拟；仅列无新增内容的可选应急索引，写明当前无法实施覆盖目标，极限模式。 |
| H为负、超过每日24小时或问诊字段相互冲突 | 不把无效值带入公式；按H未知处理并记录需确认项。 |

未知预算分支中的“最小任务包”只能证明内容闭环，不能证明时间足够。仍交付必要的模块化文件，但不以大量新增题目冒充个性化负荷；候补训练和完整模拟放在非必做位置，并说明是否完成取决于真实剩余时间。

## 3. 先选完整可学的任务包

1. 把每个候选K扩展为它及尚未掌握前置的传递闭包，组合成可独立完成的增量包。闭包中只允许资料支持的K；前置不存在或无法读取时，该任务包不能进入可靠必学范围。
2. 对任务包汇总尚未计入的阅读、回忆、代表题及核对成本；候选主考点再高分也不能绕开这些成本。若多个考点互相依赖，合并成一包；无法形成可教的闭环时转入风险并排除。
3. 依固定优先级与已知题型的必要覆盖选包；分值结构可核验时对各不重叠分值单元计一次，先尝试临时及格覆盖，再尝试安全余量目标。联合题单元仅当其全部必要K已选入才算覆盖，不重复累计多题共用的分值。
4. 每选入一包检查总预算与每日负荷，保留所需前置在相同或更早日期。如果高优先包的闭包放不下，可以选择次高且能完整学会的包；在01说明是前置成本导致的取舍。
5. 分值未知或预算未知时停止数值目标判断，使用高证据最小闭环与风险声明；不能用选入考点数量百分比宣称已经覆盖及格分值。

## 4. 压缩顺序与模式判定

对已编排的内容依次压缩，压缩后重新计算前置闭包和覆盖，不只是删短讲解：

1. 删除“有余力再学”的默认任务及低价值重复练习。
2. 减少“安全余量”的考点和重复题量，先保留能支撑核心题型的代表题。
3. 若安全覆盖目标仍明显排不下，进入**极限保命模式**；只选单位时间价值高、证据较强、能形成最小掌握闭环的包。分值/耗时未知时用已定义的保守排序替代，不编造效率。
4. 核心目标也排不下时缩小必须掌握范围，并把未选核心考点及其题型风险单列为“来不及可放弃”。不得把必需前置、正确性条件、题目核对或风险提示删掉来制造已完成假象。

**普通保命模式**要求：预算已知、最小任务可估时、安排可以容纳计划采用的安全覆盖范围；有本次分值结构时可说明选材如何接近G，只有历史代理或分值未知时明确“目标达成未验证”。**极限保命模式**用于已知时间明显不足，或预算未知且只能保守收缩。两种模式都不表示预期成绩。

完整模拟卷仍属于06的交付内容，但只有包含作答和核对的全部成本能放入预算时，才列为必做。时间不足可标为选做并按已编号专项抽题验收；不能声称做了几道抽题就已完成整卷或模拟评分。

## 5. 1天、3天、7天的编排方式

以下是任务顺序，不是保证能完成的固定题量；每次必须根据H、成本和所选包生成实际数量。相同学生条件下，1天核心预算为 `0.8H`，3天为 `2.4H`，7天为 `5.6H`（均假设每日可用H、无不可学习日），内容随预算变化；不能三种情况只改日期、保留同一任务清单。

| 可用日期 | 默认任务组织 | 压缩重点 |
|---|---|---|
| 1天 | 仅最高价值可完成闭包；03最小讲解→实际04工具→一组精选原题/专项→07核对→08/09回忆。预算允许才加下一个包。 | 通常取消扩展和多轮重复，模拟不默认必做；是否极限模式仍由成本和目标判断。 |
| 3天 | 第1天补必要前置并完成最高优先包；第2天完成其余核心，容纳时加安全余量；第3天以核对、关键回忆和资料支持的题型验收为主。 | 未形成掌握的核心优先于新余量；整卷是否必做由完整成本决定。 |
| 7天 | 第1至2天按依赖完成前置与核心；第3至4天完成核心题型并加入可容纳的安全余量；第5至6天安排专项、必要时整卷与复盘；最后一天回忆和纠错。 | 多出的时间用于已有考点练习与复核，不扩展资料外知识；低收益内容仍可放弃。 |

D为其他正整数时沿用“前置与核心→余量→验收纠错”的顺序，逐日期列出具体任务。D≥2时最后一天以已学内容的复核为主；不能把全部核心新知识留到最后一天。D=1时学习与核对在同一天闭合。

## 6. 每日条目的必备字段

每个已核算日期填写：

- **今天必须完成**：有顺序的任务包，含 K ID；阅读用完整相对文件链接加明确小节锚点，不复制知识正文。
- **练习数量和题号**：例如“精选原题2题：O001、O004；专项1题：T002”，均链接实际存在的题目。不能只写“做适量题”。模拟题使用 M001 等稳定ID；不同卷也不得重用ID。
- **验收结果**：用本题型的可观察最小掌握标准，例如“遮住答案能复述K的必要条件”“独立写出题目要求的全部关键步骤并与07核对”。阈值取自资料支持的关键词/步骤，不编造课程评分要求。
- **预计负荷**：可选显示合计区间及估计说明，必须在内部核对不超过当日预算；它不是小时段安排。
- **若未完成，明日先补**：列一项最高优先级的缺口；次日先用预留缓冲，仍不够则替换次日最低优先级余量/重复训练，重新核算，不把两天任务叠加成超额日程。最后一天改写“若未完成，放弃低优先任务，只复核核心及09”，不指向考试当天追加任务。

日期或H未知时按上文异常分支降级此结构，明确哪些字段无法可靠填写；不能输出伪造日期、假精确题量或已满足负荷的结论。

## 7. 交叉检查

交付前按[质量检查](quality-checklist.md)确认：日程止于考试前一天；选入K的所有前置都已处理；题量与可用题号一致；O/T/M在07有答案；03与实际04链接可达；每日及总成本不超预算；压缩删除的内容未残留为必做；01、02、03、09、10的模式与弃学范围一致。时间不足和未知预算必须在00醒目说明，不能只藏在风险文件。
