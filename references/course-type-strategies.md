# 课程类型判断与专属工具

在资料体检通过后，先完成类型判断，再按[考点排序规则](exam-point-ranking.md)选内容。类型是当前考试得分任务的分类，不是对课程名称的刻板分类。

## 1. 根据题目判断

1. 按本次老师明确考试说明、老师复习要求、往年题/模拟题/课程复习题、Tutorial/作业的顺序检查题目。优先采用能代表本次考试范围的证据，记录与旧卷范围的差异。
2. 给可读、范围内的题目或明确子问标记任务类型：
   - **背诵任务**：复述、解释、比较概念，按资料给出定义、简答、论述或案例论证；得分依赖关键词与逻辑表达。
   - **计算任务**：公式使用、计算过程、证明、推导、编程步骤或标准化解题流程；得分依赖操作步骤与结果。
   - **联合任务**：同时需要概念阐释和计算/操作。资料有独立子问和分值则分别计；不能拆分则保留联合，不能猜比例。
3. 已知且具有代表性的分值结构优先按分值统计；无分值时按去重后的题目或子问数量作低置信度代理。标注统计口径，不把题数比例写成考试分值比例，不按课件页数计占比。
4. 单一任务占比至少70%，且证据基本覆盖考试范围、未被相反的当前老师说明否定时，可判为对应单类。70%是本 Skill 的操作阈值，不是课程事实。背诵/计算均占明显比例、联合任务较多、样本过少或代表性无法判断时，采用**混合型（暂定）**，写明原因。

没有往年题不自动阻断；可依据完整课件、复习资料和带答案 Tutorial 判断，同时降低考情置信度。课程名称只能提供标签，不能替代以上证据。开卷不自动取消记忆工具，闭卷不自动变成背诵型；工具选择仍由题目决定。

## 2. 03与04的分工

`03_保命考点与零基础速学笔记.md` 是唯一完整知识正文，按 K ID 编写零基础解释、必须记住内容、典型考法、最小掌握标准及关联。

04仅提供已经在03中讲清楚的内容的压缩调用工具：检索表、关键词串联、最小公式摘要、答题骨架和检查动作。每行或每个工具关联 K ID 并链接03；可以重列必要公式、短定义关键词、条件、符号和单位，以便实际使用，不能复制整段概念解释、推导或完整例题解析。

所有实质内容只能由上传资料支持。答题模板的结构从资料题型和可靠答案抽象，不能给不存在的题型补一套课程内容。资料未出现某题型、公式或步骤分规则时写“本资料未提供，未列入”，不可用通用常识填充。口诀可重组资料已有关键词，但不得改变定义、条件或引入新结论；专业名称保留准确原文。

04正文仅生成以下三种之一；目录、导航、日程与链接同步采用实际文件名，不能交付占位名 `04_课程类型专属提分材料.md`。

## 3. 背诵型

生成 `04_背诵型专属_记忆清单与答题模板.md`，使用[背诵型模板](../templates/memorization-course.md)。

- **最小背诵清单**：每行包含 K ID、题目提示词、必须出现的关键词、资料支持的逻辑顺序、到03的链接。核心概念、定义、简答和论述按实际存在的题型列出，不扩展学科常识。
- **答题骨架**：分别抽象已出现的名词解释、简答、论述和案例题模板。用“此处填入K…中的限定条件”等引用，避免在工具中重复课程讲解。最低版本不能删掉改变正确性的限定条件；无可靠评分细则时称“最小可核验答案”，不保证其能取得及格题分。
- **易混辨别**：以资料中的区分标准做两列对比及一句检查动作；区别并非资料可确认时转入风险，不能自行推断。
- **记忆工具**：短缩写、分类、关键词串联及最小背诵版本。帮助记忆的表达与原定义分开标示，反向核对不遗漏关键词和否定词。
- **最小验收**：合上03后按题目提示复述关键项，再做对应原题并到07核对遗漏。未通过时补关键词和逻辑顺序，不重复阅读无关章节。

## 4. 计算型

生成 `04_计算型专属_公式清单与题型套路.md`，使用[计算型模板](../templates/calculation-course.md)。

- **最小公式表**：K ID、公式、符号含义、资料给出的适用条件、单位、允许变形与03链接。无量纲或确实不适用时写明；单位或条件不明且影响正确应用时，不把该公式列为可靠工具，转入风险。不得凭记忆补单位或推导。
- **题目提示词→操作**：把上传题目中的识别词映射到公式或资料已示范的方法，包含先检查哪个条件，不能声称关键词在任何题目中都适用。
- **标准步骤骨架**：按可靠答案提取“辨认条件→选方法→列式或列步骤→处理→核对”的实际必要项；证明与编程使用资料已有的证明结构、算法步骤或输出判据，不强行套数值公式。
- **最低书写内容**：列出资料支持的起手式、必要条件、关键中间步骤及结果格式。只有资料含评分细则时才能指明步骤分；没有时明确“这些是可核验步骤，能否计步骤分取决于评分规则”。
- **陷阱清单**：仅列资料中确实出现或由原题、答案对比可直接暴露的符号、单位、精度、边界条件和适用范围错误；每项配一个检查动作。
- **最小验收**：不看答案完成一题同型原题或已验证变式，能解释方法适用条件，并核对必要过程、结果和资料规定的表达格式。

## 5. 混合型

生成 `04_混合型专属_背诵公式与综合题套路.md`，使用[混合型模板](../templates/mixed-course.md)。

- 分别提供精简的概念/关键词表、公式/条件表、主观题骨架、计算步骤骨架；每项链接03，不把两类完整讲义拼接成04。
- 建立“资料中的概念条件→可用公式/方法→计算结果如何解释”的 K ID 对照。对应关系缺证据时明确空缺，不凭常识补桥梁。
- 对已出现的综合题给出拆解顺序：识别子问与条件、调用关联K、按可靠答案完成各步骤、核对前后结果是否一致。拆解只能改变呈现顺序，不能改动原答案的适用条件。
- 按已知题型分值与所选前置闭包的实际成本分配背诵、计算任务；分值未知且预算允许时，先为资料确实支持的两类核心任务各留一个最小练习闭环，再把余量交给排序更高的任务包。预算只能容纳一类时依排序保留可完成的一类，并披露另一类未覆盖，不为凑分类超额。不得固定假设各占一半。
- **最小验收**：对本轮已保留且已安排的内容分别检查概念表达与过程操作；只有联合任务已纳入学习范围、前置已掌握且预算允许时，才要求核对一题资料支持的联合任务。极限模式可以只保留其中一类得分闭环，此时04仍为混合型文件，但另一类与综合题写明未安排及风险，不为凑类型增加验收任务。不存在联合题时不强制创造综合题。

## 6. 连通性与输出检查

- 04每项工具必须能回到03中存在的 K ID；所有计划中的工具都使用实际04文件名。
- 日程引用精选原题 `O001`、专项 `T001`、模拟 `M001`；题号不能因课程类型变化而重用或冲突。
- 08只列失分风险及检查动作，09只抽取已有内容的极短提醒；它们链接03/04，不成为新增知识的存放处。
- 最低背诵版、最低书写内容和计划验收均是学习动作标准，不是题目得分保证。
