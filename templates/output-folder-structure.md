# 输出结构与模板展开协议

本文件是生成规则，不是学生学习包的一部分。先完成资料体检；通过后才使用本结构。

## 两种互斥交付

**阻断：**只交付一个独立文件 `资料读取与缺失报告.md`，按[缺失报告模板](missing-material-report.md)填写。不要创建学习包、空白占位文件或编号为 00—10 的文件。部分资料可读不等于整门课程已分析完成。

**通过：**创建一个课程文件夹和恰好 11 个独立 `.md` 文件。04 的三个名称只选择其中一个；不得同时保留通用名或其他课程类型名称。

```text
{{安全文件夹名课程名}}_期末保命学习包/
├── 00_先看这里_总导航.md
├── 01_考情判断与内容取舍.md
├── 02_每日冲刺任务清单.md
├── 03_保命考点与零基础速学笔记.md
├── {{04文件名}}
├── 05_资料原题精选.md
├── 06_针对性训练与AI融合模拟卷.md
├── 07_全部答案与解析.md
├── 08_易错点与失分提醒.md
├── 09_考前30分钟急救清单.md
└── 10_资料体检、冲突与弃学风险.md
```

| 课程判断 | `{{04文件名}}` 的唯一合法值 | 展开模板 |
|---|---|---|
| 背诵型 | `04_背诵型专属_记忆清单与答题模板.md` | [背诵型](memorization-course.md) |
| 计算型 | `04_计算型专属_公式清单与题型套路.md` | [计算型](calculation-course.md) |
| 混合型或无法可靠二分 | `04_混合型专属_背诵公式与综合题套路.md` | [混合型](mixed-course.md) |

其余 10 个文件按[通用学习包模板](study-package.md)展开。该模板按目标文件分段编排是为了供模型读取；正式交付时必须拆成独立文件，不能将该模板整体复制为一个总文档。

## 填写约定

- `{{字段}}` 是有意设计的填写槽；将其替换为本轮核验后的值。正式交付不得残留填写槽、编辑说明或虚构的示例知识。
- 标注“重复块”的部分按实际数量展开；不要输出“同上”“依此类推”或省略号。空类别写明“本轮未安排”及简短原因。
- 模板中的格式示意、生成规则、内部依据字段均不进入学生文件。只有填写后的正文进入学习包。
- 课程名包含文件系统不支持的字符时，只清理文件夹名；文件正文保留学生提供的课程名。每次运行都在新的运行目录完整生成并核验，保存为新版本，不替换学生旧包；不得留下新旧 04 混用的正式结果。
- 平台不能写文件时，按 00—10 的顺序输出 11 个分开的 Markdown 内容块，各块外明确标注精确目标文件名；让学生能够分别保存。仍然展开全部内容，不能只给目录或下载承诺。

## 编号与链接合同

| 对象 | ID 形态 | 唯一正文位置 | 对应解析位置 |
|---|---|---|---|
| 考点 | K001、K002…… | 03 | 不适用 |
| 精选原题 | O001、O002…… | 05 | 07 中同号 |
| 针对性训练 | T001、T002…… | 06 第一部分 | 07 中同号 |
| 模拟卷题目 | M001、M002…… | 06 第二部分 | 07 中同号 |

O/T/M各前缀从001连续编号。K是候选考点的稳定编号，取舍后03可以只展开非连续的K；未展开的候选只列名称或纯文本K，不创建死链接。完整重生成时可以重新编号，但整包必须同步。题内小问用 `(1)`、`(2)`，不另建顶层ID。多个模拟卷共用连续M序列，禁止每卷重置。

对应文件在标题前添加显式小写锚点，如 `<a id="k001"></a>`，再使用单独一行 `### K001`、`### O001`、`### T001`、`### M001` 作为稳定标题，在下一行写名称或正文。题目及答案分别在自己的文件中使用相同 ID 锚点；同一文件内不得重复。Markdown 链接由精确相对文件名和小写 ID 锚点构造；例如学习包中的 K001 链接目标为 `03_保命考点与零基础速学笔记.md#k001`。其他题目及答案按同一方式生成。文件名有空格时以 Markdown 尖括号包住目标或做一致的 URL 编码。

00 必须链接另外 10 个实际文件；02 的每条阅读任务必须链接对应文件并指明小节或 K ID；每个练习任务列出实际 O/T/M ID 和数量；04、08、09 回指 03 的对应 K ID，不重写知识讲解。07 每题可返回对应题目；05、06 不在题目旁放解析内容或可直接揭示解法的提示，只在文件开头统一链接 07，提醒做完后自查。

下列信息仅用于生成阶段：文件清单、页码或段落定位、证据层级、考点评分分项、题目溯源、仿题变换过程、比例统计的逐题依据。不得把内部映射作为附录或隐藏表写入学生包。10 和阻断报告可以列出需修复或确认的文件及可识别位置，但不要借此逐条展示全包来源。

## 正文分工

- 03 是唯一的知识讲解正文；04 是压缩记忆或解题工具，可有少量必要公式摘要、关键词或最短答题骨架，并链接 03。
- 05、06 是题目正文，不能夹带答案；模拟卷中不出现 K ID、考点分类、高频提示、解法提示或题目来源类型。
- 题目类型只在 07 标记，使用“资料原题”“原题改编”“AI仿题”。05 文件名本身表明其来源类别，不等于要逐题重复类型标签。
- 09 只从已确定的 03、04、08 压缩，不引入新知识；10 集中写缺失、冲突、不确定性和弃学风险。
- 普通练习分组可使用考点和优先级；模拟卷只保留符合考试形式的题型名称、题号、必要作答条件、题目分值和考试说明。“选择题”等考试题型名称允许；“AI仿题”等来源类型不允许。

交付前按[质量检查表](../references/quality-checklist.md)验证文件、所有相对链接及锚点、任务题量、知识和答案闭环；任何失败先修复。
