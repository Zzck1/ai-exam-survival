# 通用学习包正文模板

先读[输出结构与编号协议](output-folder-structure.md)。本文件供生成者展开，不是最终的长篇学生文档。仅在资料体检通过后使用。

下面每一节对应一个独立输出文件。最终按照 00、01、02、03、04、05、06、07、08、09、10 的顺序交付，内部创作顺序按入口；04 另读课程类型专属模板。代码块是正文结构示意，填充后应保存为普通 Markdown 文件，不保留外层代码围栏、生成规则或 `{{字段}}`。

所有“链接”填写槽均生成真正的相对 Markdown 链接：方括号内写可读标题，紧接的圆括号内写实际相对文件名；考点、题目及答案加 `#k001`、`#o001`、`#t001`、`#m001` 等对应锚点。不得链接模板文件或平台本机路径。无适用内容时明确说明原因，不保留空行或空表作为交付。

**综合题：**按全部小问逐一解答，主观小问保留两种版本，计算小问保留过程，最后核对小问间条件一致。
